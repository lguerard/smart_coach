# Third-party data in `library/`

smart_coach's own code is not affected by these notices; they cover the
two data files in this folder, both generated by scripts in `scripts/`.

## `exercises_subset.json` — exercises dataset (MIT)

Text metadata (English name, target and secondary muscles, French
instructions) for the exercises the ladders in `exercise_library.py`
point at, extracted from **exercises-dataset** by Hasan Emir Yıldırım:
<https://github.com/hasaneyldrm/exercises-dataset>.

Only the MIT-licensed text data is used. The dataset's images and
animations are © Gym visual (<https://gymvisual.com/>) and are **not**
included or used here.

## `body_paths.json` — MuscleMap body outlines (MIT)

SVG path data for the front/back body figures, extracted from
**MuscleMap** by Melih Colpan: <https://github.com/melihcolpan/MuscleMap>
(converted from Swift source to JSON, base muscle groups only).
